= RabbitMQ AMQP JMS Client
include::../target/library-attributes.adoc[]
:revnumber: {project-version}

RabbitMQ AMQP JMS Client is a Java messaging client that uses AMQP 1.0.
It is a fork of https://github.com/apache/qpid-jms[Apache Qpid JMS],
published under RabbitMQ's own Maven coordinates and Java package names,
and licensed under the https://www.apache.org/licenses/LICENSE-2.0.html[Apache License 2.0].

This is a different library from the
https://github.com/rabbitmq/rabbitmq-jms-client[RabbitMQ JMS Client], which uses AMQP 0-9-1.

== Requirements

The 2.x client requires Java {java-version} or later and implements Jakarta Messaging 3.1
using the `jakarta.jms` API namespace.
Applications using `javax.jms` should use the 1.x client line instead.

For JMS support with RabbitMQ, use Tanzu RabbitMQ with the `rabbitmq_jms` plugin enabled.
This plugin is not part of open-source RabbitMQ.
The `rabbitmq_jms_management` plugin adds management UI support.
Tanzu RabbitMQ 4.4 supports both JMS queues and JMS topics with this client.

== Dependency

Add the client to your application with Maven:

[source,xml,subs="attributes,specialcharacters"]
----
<dependency>
  <groupId>{project-group-id}</groupId>
  <artifactId>{project-artifact-id}</artifactId>
  <version>{project-version}</version>
</dependency>
----

Or with Gradle:

[source,groovy,subs="attributes,specialcharacters"]
----
implementation '{project-group-id}:{project-artifact-id}:{project-version}'
----

The client implementation uses the `com.rabbitmq.client.jms` package,
for example `com.rabbitmq.client.jms.JmsConnectionFactory`.
The messaging API types use `jakarta.jms`.

=== Snapshot repository

Versions ending in `-SNAPSHOT` require the snapshot repository.
For Maven, add:

[source,xml]
----
<repositories>
  <repository>
    <id>central-portal-snapshots</id>
    <url>https://central.sonatype.com/repository/maven-snapshots/</url>
    <snapshots><enabled>true</enabled></snapshots>
    <releases><enabled>false</enabled></releases>
  </repository>
</repositories>
----

For Gradle:

[source,groovy]
----
repositories {
  mavenCentral()
  maven {
    url = uri('https://central.sonatype.com/repository/maven-snapshots/')
    mavenContent { snapshotsOnly() }
    content { includeModule('com.rabbitmq.client', 'jms-client') }
  }
}
----

Release versions use Maven Central and do not require the snapshot repository.
